# 前端目录结构说明

> 适用项目：xuanchen-monolithic（萱晨单体项目）
> 前端工程：`FrontEnd/xuanchen-vue3`（Vue 3 + TypeScript + Ant Design Vue + Vite）
> 本文描述前端 `src/` 目录的组织规范，供开发与网站说明使用。所有业务模块均已按此规范对齐。

---

```
FrontEnd/xuanchen-vue3/src/

├── types/                      # 全局类型声明

├── utils/

│   ├── httpRequest.ts          # axios 实例（拦截器、Token、错误处理）
│   ├── fileMd5.ts

│   └── menuIcons.ts
```

## 三、核心规范：CRUD 模块「四件套」

所有标准的增删改查（CRUD）模块均采用统一的「四件套 + 弹窗目录」结构。以主数据管理中的岗位模块为基准示例：

```
views/masterdata/post/
├── PostList.vue               # 列表页（主页面，基于 XCListPage 组件）
├── post.api.ts                # 接口层：URL 枚举 + 接口函数
├── post.data.ts               # 配置层：表格列、查询表单项、状态映射
├── post.types.ts              # 类型层：业务 interface / type
└── modal/                     # 弹窗目录
    ├── Operation.vue          # 新增/编辑弹窗
    └── AssignUser.vue         # 其他业务弹窗（如分配人员）
```

### 各文件职责

| 文件 | 职责 | 约定 |
|---|---|---|
| `XxxList.vue` | 列表主页面 | 使用 `XCListPage` 组件，通过插槽定制操作列、单元格、弹窗 |
| `xxx.api.ts` | 接口定义 | 用 `enum XxxApiUrl` 收敛所有后端地址，导出类型化的接口函数 |
| `xxx.data.ts` | 页面配置 | 表格列 `columnsIndex`、查询表单 `queryFormItems`、查询参数 `queryParams`、状态颜色/文案映射 |
| `xxx.types.ts` | 业务类型 | 所有 interface/type 放这里，不与 api/data 混放 |
| `modal/` | 弹窗组件 | 每个弹窗暴露 `show()` 方法，由列表页通过 `ref` 调起 |

### 接口地址枚举命名约定（xxx.api.ts）

枚举成员按「业务块前缀 + 操作」分组命名：

| 前缀 | 用途 | 示例 |
|---|---|---|
| `INDEX_` | 列表页操作（查询/删除/导出/改状态） | `INDEX_LIST`、`INDEX_DELETE`、`INDEX_EXPORT_EXCEL` |
| `OPERATION_` | 当前页面内的增删改等操作 | `OPERATION_ADD`、`OPERATION_EDIT`、`OPERATION_CHANGE_STATUS` |
| `RECBIN_` | 回收站 | `RECBIN_LIST`、`RECBIN_REVERT` |
| `SELECT` | 下拉选项等对外查询 | `SELECT = '/system/dict/select'` |
| 功能块前缀 | 同页面的其他功能块 | `ASSIGN_USER_`（分配人员）、`UPLOAD_`（上传）、`EDITOR_`（编辑器） |

### 子组件目录约定

| 目录 | 放什么 | 识别特征 |
|---|---|---|
| `modal/` | 弹窗组件 | `<a-modal>` / `<XCModal>` + `defineExpose({ show })`，临时拉起 |
| `components/` | 子面板组件 | 父页面拆分出来的常驻组成部分（如部门树、属性面板） |

> 注：`modules/` 命名已废弃，统一使用 `components/`。

### 页面类型约定

| 页面 | 命名 | 说明 |
|---|---|---|
| 列表页 | `XxxList.vue` | 主页面，多数基于 XCListPage |
| 独立编辑器/设计器 | `XxxEditor.vue` / `XxxDesigner.vue` | 路由级独立页面（如脑图编辑器、报表设计器），浏览器可直接跳转，不放入 modal/ |
| 详情/子列表 | `XxxDetail.vue` / `XxxItemList.vue` | 列表页的附属页面 |

## 四、共享组件库（components/xuanchen）

跨业务复用的通用组件统一以 `XC` 为前缀，放在 `src/components/xuanchen/`：

| 组件 | 用途 |
|---|---|
| `XCListPage.vue` | CRUD 列表页标准骨架：查询区 / 工具栏 / 表格 / 回收站 / 弹窗插槽 |
| `XCModal.vue` | 弹窗标准骨架（全屏按钮、统一头部） |
| `XCQueryForm.vue` | 查询表单渲染器 |
| `XCRecycleBin.vue` | 回收站标准界面 |
| `XCSelect.vue` | 通用下拉（支持字典/远程数据） |
| `XCUploadFile.vue` / `XCUploadImage.vue` | 文件/图片上传（含分片、秒传） |
| `XCCadViewer.vue` / `XCOfficeViewer.vue` | CAD / Office 在线预览 |
| `XCAiAssistant.vue` | AI 助手悬浮窗 |
| `XCFormRender.vue` | 在线表单渲染器（配合业务流程模块） |
| `XCWatermark.vue` / `XCTipIcon.vue` | 水印 / 提示图标 |

另有 `components/xuanchen/businessprocess/` 存放审批流专用共享组件（审批弹窗、委托弹窗、BPMN 预览）。

## 五、各业务模块结构一览

### 5.1 system 系统管理

- **标准 CRUD 模块**（四件套 + modal，结构完全一致）：
  `post`（岗位·基准）、`account`（账号）、`person`（人员）、`role`（角色）、
  `config`（参数配置）、`menu`（菜单·树形）、`dict`（字典·含字典项子表）、`todo`（待办）
- `notice`（公告）：四件套 + 多页面（用户侧列表 / 管理员列表 / 已读状态 / 发布页）
- `dept`（部门）：树形组合页，`components/` 存放部门树、信息面板、人员面板
- `index`（工作台）、`usercenter`（个人中心）：非 CRUD 仪表页，`components/` 存放卡片面板

### 5.2 generator 代码生成

`gendatabase`（数据源）、`gentable`（表配置）、`profile`（生成配置）三个模块均为标准四件套。
`gentable` 的配置面板（表配置/列配置/目录选择器）放 `components/`，预览与生成日志弹窗放 `modal/`。
`menuTree.ts` 为模块间共享的菜单树工具。

### 5.3 online 在线办公

每个功能独立成目录、自带四件套：

```
online/
├── mindmap/   MindMapList.vue + MindMapEditor.vue + mindmap.api/data/types.ts
├── diagram/   DiagramList.vue + DiagramEditor.vue + diagram.api/data/types.ts
└── doc/       DocList.vue + doc.api/data/types.ts
```

> 编辑器（Editor）是路由级独立页面，与 List 同级放置，不放 modal/。

### 5.4 ai

- `knowledge`（知识库）：四件套 + modal（新增编辑 / 文本录入 / 文件选择）
- `assistant`（AI 助手）：`ai.api.ts` + `useAiChat.ts` 组合式函数，无页面

### 5.5 businessprocess 业务流程

业务高度内聚，接口按业务块分组在根级 `businessprocess.api.ts`（枚举前缀：`INDEX_DEFINITION_` / `OPERATION_` / `DESIGN_` / `TASK_` / `INSTANCE_` / `DELEGATE_`）：

```
businessprocess/
├── businessprocess.api.ts / .data.ts / .types.ts
├── definition/  DefinitionList.vue + modal/Operation.vue   # 流程定义
├── form/        FormList.vue + FormDesigner.vue            # 在线表单
├── design/      BusinessProcessDesigner.vue                # 流程设计器（路由级）
└── apply/ todo/ done/ mine/                               # 发起/待办/已办/我的（卡片列表）
```

### 5.6 visualization 大屏可视化

根级四件套 + 列表页；设计器目录 `design/` 内含画布、属性面板、组件库（`components/`）与数据集弹窗（`modal/`）；`viewer/` 为渲染查看页。

### 5.7 report 报表

根级四件套 + 列表页；`template/` 子模块（模板列表 + 设计器，自带 modal）；`design/` 存放设计器面板；`viewer/` 存放渲染引擎（渲染/导出/填报）。

### 5.8 filemanage 文件中心

根级四件套，接口枚举按功能块分组（`INDEX_MY_` / `RECBIN_` / `UPLOAD_` / `SHARE_` / `FOLDER_` / `QUOTA_` / `OFFICE_`）：

```
filemanage/
├── filemanage.api.ts / .data.ts / .types.ts
├── my/MyFileList.vue          # 我的文件（XCListPage）
├── recycle/RecycleList.vue    # 回收站（XCListPage）
├── quota/QuotaList.vue        # 配额管理（管理员）
├── share/ShareView.vue        # 外链分享页
└── OfficeEditor.vue           # Office 在线编辑（路由级）
```

### 5.9 monitor 系统监控

7 个子模块结构完全一致（`XxxIndex/XxxList.vue` + `xxx.api/data/types.ts`）：
`cache`（缓存）、`server`（服务器）、`loglogin` / `logoperation` / `logapi` / `loggenerator`（四类日志）、`onlineuser`（在线用户）。
日志类为标准列表页；缓存/服务器为单页仪表展示。

### 5.10 api / auth / error

- `api`（数据接口管理）：`api/` 子目录存放接口列表与向导式编辑器，`data/` 存放数据源列表
- `auth`（认证）：登录、注册、强制改密 + modal（滑块验证、忘记密码）
- `error`：404 页面

## 六、新模块开发清单

新增一个标准 CRUD 模块时，按以下清单创建文件：

```
views/<业务域>/<模块名>/
├── XxxList.vue        # ① 列表页：复制 PostList.vue 骨架，替换 columns 与 url
├── xxx.api.ts         # ② 接口：定义 enum XxxApiUrl（INDEX_/OPERATION_/RECBIN_）+ 接口函数
├── xxx.data.ts        # ③ 配置：columnsIndex / queryFormItems / queryParams
├── xxx.types.ts       # ④ 类型：列表行 Record、保存参数 SaveParams
└── modal/Operation.vue # ⑤ 弹窗：复制 post/modal/Operation.vue 骨架
```

并在 `router/index.ts` 注册路由（列表页 + 可选的编辑器/详情页）。
